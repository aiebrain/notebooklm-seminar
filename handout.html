🔍 STEP 1 — Grok Deep Research로 자료 조사

일론 머스크의 xAI가 만든 AI. Deep Research 모드로 주제를 깊이 조사해 보고서를 자동 생성합니다.

핵심 클릭 순서

  1. grok.com 접속
  2. 좌측 메뉴에서 Deep Research 선택
  3. 검색창에 구체적 주제 입력 (예: "2025년 AI 마케팅 트렌드")
  4. AI가 2~3분간 웹 검색 → 보고서 자동 생성
  5. 텍스트 전체 선택 (Ctrl+A) → 복사 (Ctrl+C)
  6. 메모장에 붙여넣기 → .txt 파일로 바탕화면에 저장

📄 STEP 2 — NotebookLM 소스 입력

Google이 만든 AI 리서치 어시스턴트. 내가 올린 자료만 분석하므로 거짓 정보(할루시네이션)가 거의 없습니다.

핵심 클릭 순서

  1. notebooklm.google 접속
  2. 새 노트북 클릭
  3. 좌측 "+" 소스 추가 → "파일 업로드" → Grok .txt 파일 선택
  4. "+" 소스 추가 → "유튜브" 선택 → 관련 영상 URL 2~3개 붙여넣기
  5. 채팅창에 테스트: "이 자료들의 핵심을 3줄로 요약해 줘"

🎤 STEP 3 — AI 팟캐스트 (오디오 오버뷰) 생성

내 자료를 바탕으로 2명의 AI 호스트가 대화하는 팟캐스트를 자동 생성합니다. 클릭 한 번이면 끝!

핵심 클릭 순서

  1. NotebookLM 우측 패널 오디오 오버뷰 열기
  2. (선택) "커스터마이즈"에서 초점 주제 지정
  3. "생성" 버튼 클릭 → 3~5분 대기
  4. 재생 버튼으로 내용 확인
  5. 다운로드(↓) 아이콘 → MP3 파일로 바탕화면에 저장

✅ 결과물 1 AI 팟캐스트 (MP3) 완성!

🎬 STEP 4 — 팟캐스트를 숏폼 영상으로 변환

MP3 팟캐스트에 배경 영상을 입히고, 자동 자막까지 추가하여 유튜브/릴스/틱톡용 영상을 완성합니다.

4-A Brue — 오디오를 영상으로

핵심 클릭 순서

  1. Brue 접속 및 로그인
  2. Upload Audio → 다운로드한 팟캐스트 MP3 선택
  3. AI가 음성을 분석해 어울리는 배경 영상 자동 매칭
  4. 결과 영상 확인 → 다운로드

4-B CapCut — 자동 자막 입히기

핵심 클릭 순서

  1. capcut.com 접속 → 새 프로젝트
  2. Brue에서 만든 영상 파일 업로드
  3. "텍스트" 메뉴 → 자동 캡션 클릭
  4. 언어: 한국어 선택 → "생성" (1~2분 대기)
  5. 자막 클릭 → 스타일 탭에서 폰트/크기/색상 수정

4-C 영상 내보내기

내보내기 설정

  1. 화면 비율: 9:16 (세로형) — 숏츠/릴스 필수
  2. 우측 상단 내보내기 클릭
  3. 해상도: 1080p
  4. 다운로드 → MP4 파일로 저장

✅ 결과물 2 자막 숏폼 영상 (MP4) 완성!

📊 STEP 5 — PPT 슬라이드 자동 생성

5-A 디자인 레퍼런스 수집

  1. behance.net 또는 dribbble.com 접속
  2. 검색: "presentation design" 또는 "infographic"
  3. 마음에 드는 디자인 페이지 열기
  4. 크롬 확장 GoFullPage 아이콘 클릭 → 전체 페이지 캡처 → PNG 다운로드

5-B Gemini로 컬러 HEX 추출

  1. gemini.google.com 접속
  2. 캡처한 디자인 이미지 업로드 (📎 클릭)
  3. 프롬프트 A 붙여넣기 → 전송
  4. AI가 HEX 컬러 코드 + 디자인 분석 결과 출력

5-C NotebookLM PPT 구조화 + Google Slides

  1. NotebookLM 채팅창에 프롬프트 B (마스터 대본) 붙여넣기
  2. Target Audience와 Objective 변수 채우기 → 전송
  3. AI가 슬라이드별 제목 + 본문 대본 자동 생성
  4. slides.google.com → "빈 프레젠테이션" 열기
  5. NotebookLM 결과를 슬라이드에 복사/붙여넣기
  6. 배경색/글자색에 HEX 코드 입력하여 테마 통일

✅ 결과물 3 전문가급 PPT 슬라이드 완성!

📱 STEP 6 — 카드뉴스 제작 (Canva)

  1. canva.com 접속 및 로그인
  2. 검색: "카드뉴스" 또는 "인스타그램 게시물"
  3. 텍스트가 큼직한 템플릿 선택
  4. 기본 텍스트 삭제 → NotebookLM 핵심 내용 붙여넣기
  5. PPT와 동일한 HEX 컬러 적용 (브랜드 통일)
  6. 5~7장 분량 확인 → 커버 제목 임팩트 체크
  7. 우측 상단 "공유" → "다운로드" → PNG → 다운로드

✅ 결과물 4 SNS 카드뉴스 (PNG) 완성!
