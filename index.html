NotebookLM이란?

구글이 만든 무료 AI 리서치 도구

구글 계정만 있으면 바로 시작

✅

사전 준비

아래 3가지만 준비하세요

1️⃣ 구글 계정 — 로그인 필수

2️⃣ Grok — grok.com 접속 확인

3️⃣ 관심 주제 — 리서치할 키워드 1개

STEP 1
🔍

Deep Research

Grok(grok.com)으로 주제 심층 리서치

핵심 데이터 · 팩트 · 통계를 텍스트로 정리

💡 Grok 활용 팁

🎯 구체적 키워드로 질문하기

📊 숫자·통계·트렌드 데이터 요청

📋 결과물을 텍스트로 복사 → NotebookLM 소스로 활용

🔄 여러 번 질문해서 풍부한 자료 확보

STEP 2
🔗

유튜브 링크 입력

NotebookLM에 유튜브 URL 붙여넣기

Grok 리서치 + 유튜브 = 복합 소스

STEP 3
🎙️

팟캐스트 생성

Audio Overview 클릭 → 초점 주제 지정

생성 대기 5~8분 → AI가 대화형 팟캐스트 완성

🎉

결과물 ① 완성!

🎙️

AI 팟캐스트

MP3 다운로드 → 바로 사용 가능

STEP 4
📱

SNS 카드뉴스

NotebookLM 채팅 → 핵심 내용을 카드뉴스 문구로 추출

인스타 · 블로그용 3~5장 제작

STEP 4

🎨 Canva 실습

1️⃣ Canva 접속 → 템플릿 선택

2️⃣ NotebookLM 추출 문구 배치

3️⃣ 색상 · 폰트 · 이미지 조정

4️⃣ PNG 다운로드

결과물 ② SNS 카드뉴스 완성!

STEP 5
🎬

영상 제작

CapCut 웹(무료)으로 팟캐스트 + 카드뉴스 합치기

팟캐스트가 내레이션, 카드뉴스가 화면

STEP 5

🎞️ CapCut 실습 흐름

1️⃣ 새 프로젝트 → MP3 업로드 (5분)

2️⃣ 카드뉴스 이미지 순서 배치 (5분)

3️⃣ 자동 자막 생성 (10분)

4️⃣ 1080p 내보내기 (5분)
